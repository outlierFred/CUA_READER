# CUA Reader

## Use it

1. Open the site.
2. Paste the full JSON response into the large box. CUA Reader validates it as you type and pinpoints syntax errors by line and column.
3. Optionally select **Format JSON** to pretty-print valid JSON.
4. Select **Find input links**.
5. Select any filename to open its link.

Everything happens in your browser. The content you paste is not uploaded or saved.
